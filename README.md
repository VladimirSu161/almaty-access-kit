# Рабочий доступ через Алматы — 1.0.0

Комплект для пошаговой настройки: Claude отвечает в отдельном Google Chrome и работает с локальными файлами через Claude Code. Трафик идёт через твой собственный VPS в Алматы. На Mac терминал — iTerm2, на Windows — WSL2/Ubuntu.

SHA-256 архива: `ae7ccd4fced0c38bdbba8d2f2aac62d16541f2213a089253872b352e4728eeda`

## Как начать

1. Распакуй весь ZIP и открой «НАЧНИ ЗДЕСЬ.html» двойным щелчком.
2. Открой эту же папку как проект в своём работающем Codex.
3. Отправь агенту текст из файла `START.txt`.

Агент ведёт по одному шагу: проверка компьютера → свой VPS → настройки → проверки → вход → Claude в Chrome и Claude Code в терминале.

Если HTML не открывается, начни с `SETUP.md`. Целостность файлов проверяется командой `python3 kit.py verify --manifest MANIFEST.sha256`.

## Важно

- Сервер, аккаунты и оплата твои. Секреты в чат не отправляй.
- Mac проверен автором. Windows и Linux проверяются на твоём компьютере вместе с агентом, работа на всех конфигурациях не обещана.
