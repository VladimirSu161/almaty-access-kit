# Работа с комплектом

Прочитай SETUP.md, compatibility.json и skills/almaty-access/SKILL.md. Это полный
маршрут установки вместе с агентом, версия 1.0.0. Скилл локальный; отдельная
глобальная установка не нужна.

Доведи получателя до реальных ответов Claude в отдельном Google Chrome и
Claude Code в терминале, затем до повторного запуска обоих. На Mac используй
iTerm2. Опись и сгенерированные файлы — промежуточные результаты.

Проверки выполняются на компьютере получателя. Не останавливай установку
из-за отсутствия у автора Windows/Linux или старого статуса rc1. При ошибке
найди причину, исправь в выбранном маршруте, повтори затронутую проверку и
продолжай. Конкретный неустранённый отказ останавливает зависимый шаг; сохрани
диагноз и следующее действие, а не общий ответ «версия не принята».

Говори по-русски, по одному действию. Сначала опись; перед очисткой покажи
точные пути и последствия, перед заказом — сумму, перед обрывом — восстановление.
Личный вход, платёж и документы выполняет владелец в интерфейсе сервиса.
Не меняй сеть или глобальные инструкции Codex. Не удаляй проекты, историю,
скиллы и чужие службы. Не выводи секреты и не помещай их в архив.

На Mac браузер использует единственный HTTP proxy без DIRECT, с проверкой
IP и остановки свежих запросов при отказе; внешнего firewall всего Chrome
шаблон не устанавливает. CLI имеет свою внешнюю границу. На Linux/WSL
используется отдельная сетевая среда CLI и браузера. Не отключай TLS,
штатный sandbox Chrome или изоляцию ради успеха и не запускай обычный
браузер/CLI как скрытый запасной путь. Не заявляй 100% защиту всех механизмов.
