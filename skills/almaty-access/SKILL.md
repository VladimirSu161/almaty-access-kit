# Рабочий доступ через Алматы

Работай с целой распакованной папкой. Найди корень по SETUP.md и compatibility.json,
прочитай [маршрут](../../SETUP.md) и [статус платформ](../../compatibility.json).
Отдельная глобальная установка этого скилла не нужна.

Цель — ответы в веб-чате Claude отдельного Google Chrome, задача с локальными
файлами в Claude Code и повторное открытие обоих. На Mac используй iTerm2.
Не заканчивай на описи, конфигурациях, IP-check или одном OAuth.

Режимы:
- Новая установка: опись → [очистка при необходимости](../../guides/cleanup.md) →
  [свой сервер](../../guides/server.md) → платформа → [приёмка](../../guides/verification.md) →
  личный вход, web-chat и CLI → ежедневный запуск.
- Продолжение: progress.json → фактическое состояние → незавершённый шаг.
- Сбой: [диагностика](../../guides/troubleshooting.md), без повторной очистки.
- Обновление: сохранность данных, путь запуска, повтор затронутых проверок.

Платформы: [macOS](../../platforms/macos/README.md), [Ubuntu](../../platforms/linux/README.md),
[Windows 11/WSL2](../../platforms/windows/README.md). Различаются стек и команды,
конечный результат одинаковый. Author runtime unknown означает «проверь здесь»,
а не «ждать разрешения автора». Уточняй действующие официальные документы при
несовместимости, исправляй конкретную причину, проверяй и продолжай. Не выдавай
неудачную проверку за успешную; при внешнем препятствии запиши точно, что нужно
от владельца/провайдера. Произвольную смену провайдера, VM или платного сетевого
продукта отдельно согласуй: это меняет условия установки.

Человеку: зачем шаг → одно действие → наблюдаемый результат. Ключи, пароли,
одноразовые URL/коды и cookies не выводить. До изменения сохраняй запись в
install-manifest.json с точным откатом. Перед удалением входа — список и согласие,
перед заказом — стоимость, перед обрывом — восстановление. Чтение и обычная
диагностика не требуют постоянных повторных подтверждений.

Одинаковая цель не означает одинаковую изоляцию: Mac Chrome — отдельный профиль
с фиксированным proxy и проверенным отказом веб-запросов; полный OS-firewall не
заявлен. CLI Mac и общий Linux/WSL сеанс имеют внешние ограничения. Не выключай
TLS/Chrome sandbox и не добавляй direct fallback. Вход — после обязательных
проверок выбранного маршрута на этой машине, а не после старого протокола автора.

kit.py только читает/подготавливает файлы; он не устанавливает сеть. Записывай
прогресс без секретов и не смешивай ручные HTML-галочки с техническими фактами.
